description: Manage named client style-guide profiles (save, load, list, show, update, reset, delete)
argument-hint: <verb> [slug]
---

Thin wrapper over the profiles reference. Load `skills/diagram-design/references/profiles.md` and apply the profile verb given as `$ARGUMENTS` (`save`, `load`/`switch`, `list`, `show`, `update`, `reset`, `delete`). Profiles live under `~/.diagram-design/profiles/` — never inside an installed plugin directory.
